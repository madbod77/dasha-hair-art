# dasha.hair.art

Готовий адаптивний сайт перукаря-колориста у Хмельницькому. Українська мова, справжні фото з Instagram, локальні шрифти та асети. HTML, CSS і JavaScript без залежностей.

## Публічний сайт

Сайт: https://madbod77.github.io/dasha-hair-art/

Репозиторій: https://github.com/madbod77/dasha-hair-art

GitHub Pages публікує файли з кореня гілки `main`. `.nojekyll` вимикає обробку Jekyll. Після зміни HTML, CSS, JavaScript чи асетів зробіть commit і push у `main`; статус розгортання можна перевірити на вкладці Actions.

## Перегляд

Відкрийте `index.html` у браузері. Галерея, меню та вибір послуги працюють локально; якщо браузер обмежує буфер обміну, текст виділяється для ручного копіювання.

Для локального HTTP-перегляду з цієї теки:

```sh
python3 -m http.server 4189 --bind 127.0.0.1
```

Адреса: http://127.0.0.1:4189

## Що працює

- Адаптивна сторінка, меню на телефоні, навігація до розділів.
- Розгортання описів послуг.
- Фільтри портфоліо; перегляд фото з кнопками, стрілками клавіатури, Escape та поверненням фокуса. Без JavaScript фото відкриваються звичайними посиланнями.
- Вибір послуги й підготовка повідомлення: скопіювати текст, відкрити Instagram, надіслати власноруч.
- Посилання на Instagram та дзвінок на підтверджений номер.
- Зменшення руху за системною настройкою `prefers-reduced-motion`.
